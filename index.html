GG Daily Uploader

A private publishing tool for the GG Daily and Unfiltered Daily channels.

What it does

GG Daily Uploader is a personal, non-public tool used only by the operator of the GG Daily and Unfiltered Daily channels. It publishes short videos that the operator has already created and reviewed to the operator's own TikTok and YouTube accounts, including title, description and hashtags.

  • Only the operator's own accounts are connected – there are no other users.
  • Every video is reviewed by the operator before it is published.
  • The tool does not read, collect or store data of other users.

▶ Uses YouTube API Services

This tool uses YouTube API Services to upload the operator's own videos to their own YouTube channels. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
